# FlowKit

Free n8n, BuildShip & Make.com node library

Canonical page: https://highlevelkit.com/apps/flowkit
Provider: https://flowkit.directory
Categories: Workflow Automation, Integration Platforms, Templates & Snapshots

A community-driven repository offering 250+ ready-to-use workflow nodes for automation platforms. Browse, search, and copy nodes directly into your workflows with no setup required. Supports n8n, BuildShip, and Make.com platforms.

## Listed features
- 250+ pre-built workflow nodes
- n8n platform support
- BuildShip platform support
- Make.com platform support
- One-click copy functionality
- Node collections
