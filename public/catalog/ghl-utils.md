# GHL Utils

Quick navigation tool for GoHighLevel

Canonical page: https://highlevelkit.com/apps/ghl-utils
Provider: https://ghlutils.com
Categories: Workflow Automation, AI Tools, Widgets

A browser extension designed to save GoHighLevel users time by providing AI-powered workflow analysis, instant audit log access, and faster navigation. Debug workflows, analyze contact data, and manage multiple GHL accounts more efficiently.

## Listed features
- AI Workflow Analysis (GPT-4.1 powered)
- Instant audit log access
- Two-click workflow debugging
- Contact field inspector
- Quick search palette
- Bulk contact editor

## Use cases
- Workflow Automation
- Debugging
- Navigation
