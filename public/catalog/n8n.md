# n8n

Self-hosted workflow automation platform

Canonical page: https://highlevelkit.com/apps/n8n
Provider: https://n8n.io
Categories: Workflow Automation, Integration Platforms

n8n is a powerful, self-hosted automation platform that connects GoHighLevel with hundreds of tools and APIs without extensive coding. Create custom workflows, automate complex processes, and integrate with any service that has an API. Perfect for agencies needing advanced automation beyond GHL's built-in workflows.

## Listed features
- Self-hosted or cloud options
- 350+ integrations available
- Visual workflow builder
- GHL API connection
- Custom JavaScript code nodes
- Webhook triggers and actions

## Use cases
- Workflow Automation
- Integration
- AI Assistants
