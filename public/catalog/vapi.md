# Vapi

Voice AI agents for developers

Canonical page: https://highlevelkit.com/apps/vapi
Provider: https://vapi.ai
Categories: AI Tools, Communication, Workflow Automation

Vapi enables you to build, test, and deploy advanced voice AI agents in minutes. Create conversational voice AI that handles phone operations including customer support, appointment booking, and sales calls. Supports both inbound and outbound voice agent deployments with enterprise-grade reliability.

## Listed features
- Multilingual support (100+ languages)
- Sub-500ms latency
- Bring your own models (transcription, LLM, TTS)
- Tool calling for API integration
- A/B testing for prompts and voices
- SOC2, HIPAA, PCI compliance

## Use cases
- Voice AI
- Customer Support
- Appointment Booking
- Sales Calls
