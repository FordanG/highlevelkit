# Make

Visual automation platform for complex workflows

Canonical page: https://highlevelkit.com/apps/make
Provider: https://www.make.com
Categories: Workflow Automation, Integration Platforms

Make (formerly Integromat) is a powerful visual automation platform that connects GoHighLevel with thousands of apps. Build complex multi-step workflows with branching logic, data transformation, and error handling. Perfect for agencies needing advanced automation beyond simple triggers.

## Listed features
- Visual workflow builder
- 1000+ app integrations
- Branching and conditional logic
- Data transformation tools
- Error handling and retries
- Scheduled automations

## Use cases
- Workflow Automation
- Integration
- Data Transformation
